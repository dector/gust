gust run - run and watch a command

Usage:
  gust -e <cmd> [--e.before <cmd>]... [--e.after <cmd>]...
       [-p <port>|<app:proxy>] [-h <path>] [-T]
       [--exclude <path>] [--exclude.glob <glob>] [--optin <feature>]... [--self-dev] [-v]

Flags:
  -e <cmd>              required command, executed via /bin/sh -c
  --e.before <cmd>      command to run before each rerun, repeatable, fail-fast
  --e.after <cmd>       command to run after each start, repeatable
  -p <port>             app port, or app:proxy ports; ? selects a free port
  -h <path>             health endpoint path, requires app port
  -T                    expose proxy port if enabled, else app port via Tailscale Serve; requires -p
  --exclude <path>      path exclude, repeatable
  --exclude.glob <glob> glob exclude, repeatable
  --optin <feature>     opt-in feature, repeatable (comments; default off)
  --self-dev            allow Alt+click selection of Gust panel and reload after proxy restart; requires comments and proxy
  -v                    enable verbose Gust logs

Samples:
  gust -e 'go run ./cmd/server'
  gust -e 'go run ./cmd/server' --e.before 'templ generate' --e.before 'sqlc generate'
  gust -e 'go run ./cmd/server' --e.after 'notify-send reloaded'
  gust -e 'go run ./cmd/server' -p 8080:5000 -h /health
  gust -e 'go run ./cmd/server' -p '?:?' -h /health -T
  gust -e 'go run ./cmd/server' -p 8080 -h /health -T
  gust -e 'go run ./cmd/server' --exclude frontend/node_modules -v
  gust -e 'go run ./cmd/server' --exclude.glob '*_templ.go'
  gust -e 'go run ./cmd/server' -p 8080:5000 --optin comments

Keys (when stdin is a terminal):
  r  rerun now
  s  pause/resume auto-reload
  i  toggle info logs
  D  toggle browser debug lines (proxy mode)
  q  quit

Use -p '?' for a free app port, or -p '?:?' for free app and proxy ports.
The first candidate is path-derived, so ports stay stable when available;
occupied ports cause Gust to try the next candidate.
An empty proxy slot disables the proxy; an empty app slot cannot be proxied.
The app must listen on GUST_APP_PORT. Without -p, the app decides its own port.
Port selection and app binding are not atomic; another process can take the port.

Tailscale: -T starts Serve after proxy setup, before app readiness checks.
The proxy port is exposed when enabled;
otherwise the app port is exposed. The HTTPS port is stable for the
directory and exposed port unless occupied;
existing Serve ports are skipped. Exposure stays up across reruns and is
closed on shutdown. Failures are warnings; the app continues locally.

Comments are disabled by default. Use --optin comments to enable the browser
comments UI/API and `gust ctl comments` commands; unknown opt-in values are errors.
In --self-dev mode, Alt+click selects Gust panel elements without changing
normal panel clicks; it works with -T. Gust restarts still discard comments.

Details: see README.md and docs/before-after.md.
